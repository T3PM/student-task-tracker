# Student Task Tracker

เว็บแอปพลิเคชันสำหรับจัดการข้อมูลนักศึกษาและทดสอบกระบวนการ DevOps ด้วย Node.js และ Express.

## ความต้องการของระบบ

- Node.js รุ่น LTS (ทดสอบบน `v26.13.0`)
- npm (ทดสอบบน `11.20.0`)

## การติดตั้งและเริ่มต้นใช้งาน

1. ติดตั้ง Dependencies ของโปรเจกต์

```bash
npm install
```

2. เริ่มต้นเซิร์ฟเวอร์

```bash
npm start
```

3. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` เพื่อใช้งานหน้าเว็บจัดการข้อมูลนักศึกษา.

## เส้นทาง API

เซิร์ฟเวอร์รันที่พอร์ต `3000` และรองรับข้อมูลแบบ JSON ดังนี้:

| Method | Endpoint | คำอธิบาย |
|---|---|---|
| `GET` | `/` | แสดงหน้าเว็บ UI สำหรับเพิ่ม แสดง แก้ไข และลบข้อมูล |
| `GET` | `/students` | ดึงรายชื่อนักศึกษาทั้งหมด (`200 OK`) |
| `POST` | `/students` | เพิ่มข้อมูลนักศึกษาใหม่ด้วย `{ "name", "major" }` (`201 Created`) |
| `PUT` | `/students/:id` | แก้ไขข้อมูลนักศึกษาตาม `id` (`200 OK`) |
| `DELETE` | `/students/:id` | ลบข้อมูลนักศึกษาตาม `id` (`200 OK`) |
